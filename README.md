# API-Connect

## Objetivo
API simples para conectar front-end e back-end, demonstrando estrutura básica de um projeto Node.js com Express.

## Tecnologias Utilizadas
- Node.js
- Express.js
- JavaScript
- HTML

## Listagem Estruturada dos Exemplos
- `index.html` - Página inicial do projeto
- `server.js` - Servidor Express com endpoint /api
- `package.json` - Configuração e dependências

## Como executar localmente
1. Clone o repositório:
   git clone https://github.com/danielasampaio1/api-connect.git

2. Instale as dependências:
   npm install

3. Inicie o servidor:
   npm start

4. Acesse em http://localhost:3000

## Endpoints
- GET / - Retorna a página inicial
- GET /api - Retorna mensagem {mensagem: 'API funcionando!'}
